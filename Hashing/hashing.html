🤔 What is Hashing?

Hashing is the go-to technique when you need fast lookups, counting, or tracking elements. A hash map (dict) or hash set (set) lets you find, add or check an item in O(1) average time — turning a slow O(n) search inside a loop into an instant lookup, so the whole solution drops from O(n²) to O(n).

✅ When to use it

  • You need O(1) lookup
  • You're counting frequency of elements
  • You're checking if something exists
  • You need to find a pair in an unsorted array

💡 Key idea

Store elements and their properties (index, frequency, running sum…) in a hash map so that later you can ask “have I seen this?” in constant time instead of re-scanning the array. You trade a little memory for a lot of speed.

⚠️ Watch out for

Worst-case hash collisions can degrade lookups — but in interviews, average O(1) is what matters. Also: look up before you insert so an element never matches itself.

1 · Two Sum 🗂️ Hash Map

🔗 LeetCode 1 Easy

Don't check every pair. For each number, ask the map: “have I already seen target − x?” Lookup is O(1), so one pass is enough.

  1. Create an empty map seen  (value → index).
  2. For each x, compute need = target − x.
  3. If need is in seen → return [seen[need], i]. 🎯
  4. Otherwise store seen[x] = i and move on.
Python solution 
def two_sum(nums, target):
    seen = {}  # value -> index

    for i, x in enumerate(nums):
        need = target - x          # the number that completes the pair

        if need in seen:           # O(1) lookup
            return [seen[need], i]

        seen[x] = i                # remember x for later numbers

    return []                      # (problem guarantees we never get here)

2 · Valid Anagram 🗂️ Hash Map

🔗 LeetCode 242 Easy

Same letters, same counts. Count every character of s, then spend those counts using t. If t ever needs a letter that isn't available, it's not an anagram.

  1. Different lengths? → False immediately.
  2. Pass 1: for each char of s, count[char] += 1.
  3. Pass 2: for each char of t, if count[char] is 0 → False, else subtract 1.
  4. Finished t cleanly → True.
Python solution 
def is_anagram(s, t):
    if len(s) != len(t):
        return False

    count = {}

    # Pass 1: count every character of s
    for c in s:
        count[c] = count.get(c, 0) + 1

    # Pass 2: "spend" those counts using t
    for c in t:
        if count.get(c, 0) == 0:   # t has a char s can't supply
            return False
        count[c] -= 1

    return True

3 · Valid Sudoku 🧺 Hash Sets

🔗 LeetCode 36 Medium

Keep one set per row, per column and per 3×3 box. A digit that is already in any of its three sets means the board is invalid.

  1. Create 9 row sets, 9 column sets and 9 box sets.
  2. For each filled cell, compute its box: b = (r // 3) * 3 + c // 3.
  3. Digit already in rows[r], cols[c] or boxes[b] → invalid. ✗
  4. Otherwise add it to all three sets. No conflicts after 81 cells → valid. ✓
Python solution 
def is_valid_sudoku(board):
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]

    for r in range(9):
        for c in range(9):
            v = board[r][c]
            if v == ".":
                continue

            b = (r // 3) * 3 + c // 3        # which 3x3 box?

            if v in rows[r] or v in cols[c] or v in boxes[b]:
                return False                  # duplicate found

            rows[r].add(v)
            cols[c].add(v)
            boxes[b].add(v)

    return True

4 · Longest Consecutive Sequence 🧺 Hash Set

🔗 LeetCode 128 Medium

Sorting is too slow (O(n log n)). Put everything in a set, then only start counting from numbers that begin a run — i.e. where x − 1 is not in the set.

  1. Build num_set = set(nums) (duplicates disappear).
  2. For each x: if x − 1 is in the set, it's mid-run → skip.
  3. Otherwise x starts a run: count x+1, x+2, … while they exist.
  4. Keep the longest run length seen.
Python solution 
def longest_consecutive(nums):
    num_set = set(nums)
    best = 0

    for x in num_set:
        if x - 1 not in num_set:          # x starts a new run
            length = 1
            while x + length in num_set:  # walk the run
                length += 1
            best = max(best, length)

    return best

5 · Subarray Sum Equals K 🗂️ Prefix Sum + Map

🔗 LeetCode 560 Medium

A subarray sum is prefix[i] − prefix[j]. We need that to equal k, so at each step count how many earlier prefixes equal prefix − k.

  1. Start with freq = {0: 1} (empty prefix) and prefix = 0.
  2. Add nums[i] to prefix.
  3. count += freq.get(prefix − k, 0) — each match is a valid subarray ending at i.
  4. Then record freq[prefix] += 1.
Python solution 
def subarray_sum(nums, k):
    count = 0
    prefix = 0
    freq = {0: 1}                 # the empty prefix

    for x in nums:
        prefix += x
        count += freq.get(prefix - k, 0)       # earlier prefixes that fit
        freq[prefix] = freq.get(prefix, 0) + 1

    return count
