🤔 What is Binary Search really about?

Binary search is not just about searching a sorted array. Its real power is search space reduction: every step throws away half of the possibilities, giving O(log n) instead of O(n).

✅ When to use it

  • The input is sorted
  • The search space is monotonic: a condition flips from false → true exactly once
  • The problem asks for the minimum / maximum value that satisfies a condition
  • You want to turn an O(n) scan into O(log n)

💡 Key idea

Look at the middle. That one comparison tells you which half can't contain the answer, so you drop it and repeat on what's left. After about log₂ n steps only one candidate remains.

🔍 How to spot it

"Sorted" or "rotated sorted" in the statement? Think binary search first. "Smallest speed / capacity such that…" is binary search on the answer. "Latest value at or before X" is a floor search.
