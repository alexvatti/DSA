🤔 What makes a Medium Linked List problem?

The tools are the same as in Part 1 — next pointers, prev / curr, slow / fast, a dummy head — but a Medium problem glues two or three of them together (or adds a hash map). Name the pieces first, then code them one by one.

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

✅ When to use it

  • You need the nth node from the end
  • The new order alternates front and back
  • You must clone nodes that have extra pointers
  • Numbers are digit lists with a carry
  • An array hides a linked list / cycle
  • You need an LRU cache with O(1) operations

💡 Key idea

Break the problem into easy building blocks: a gap between two pointers, middle + reverse + merge, an old → new map, a dummy with carry, or Floyd's cycle trick. Save next before every re-link.

🔍 How to spot it

Look for nth from end, reorder, copy, add numbers, duplicate. Ask: do I need a gap? the middle? a map? a carry?
