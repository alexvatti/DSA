# Python-Based Data Structures and Algorithms (DSA)
## 25-Day Study Schedule

**Duration:** 25 Days  
**Daily Study Time:** 1 Hour  
**Total Learning Time:** 25 Hours

| Day | Topics to Cover | Practical Task |
|---:|---|---|
| 1 | Problem-Solving Fundamentals, Big O, Time and Space Complexity | Analyse simple Python programs |
| 2 | Arrays and Lists – Creation, Indexing, Traversal and Operations | Find maximum, minimum and second-largest elements |
| 3 | 2D Arrays and Strings | Matrix traversal, reverse a string and check palindrome |
| 4 | Linked Lists – Nodes, Traversal, Insertion and Deletion | Implement a singly linked list |
| 5 | Linked Lists – Searching, Reversing, Fast and Slow Pointers | Reverse a linked list and find the middle node |
| 6 | Stacks – Implementation and Operations | Implement a stack and solve balanced parentheses |
| 7 | Queues and Deques | Implement a queue and understand circular queue basics |
| 8 | Linear Search and Binary Search | Implement both and compare their complexity |
| 9 | Binary Search Variations | Find first occurrence, last occurrence and insertion position |
| 10 | Bubble Sort, Selection Sort and Insertion Sort | Implement all three sorting algorithms |
| 11 | Merge Sort and Quick Sort | Implement both and understand divide and conquer |
| 12 | Heap Sort and Counting Sort | Implement one and understand the other |
| 13 | Hashing – Dictionaries, Sets, Hash Tables and Collisions | Frequency counting and duplicate detection |
| 14 | Recursion, Recursion Trees and Divide and Conquer | Implement factorial, Fibonacci and recursive digit sum |
| 15 | Backtracking | Generate subsets and solve a simple maze problem |
| 16 | Binary Trees and Binary Search Trees | Create a tree and implement tree traversals |
| 17 | Balanced Trees, Heaps, Priority Queues and Tries | Understand operations and use Python `heapq` |
| 18 | Graph Representation, BFS and DFS | Implement graph traversal |
| 19 | Cycle Detection and Topological Sorting | Detect cycles and implement topological ordering |
| 20 | Shortest Path Algorithms and Minimum Spanning Trees | Understand Dijkstra's and Kruskal's algorithms |
| 21 | Two Pointers and Sliding Window | Solve pair-sum and maximum-sum subarray problems |
| 22 | Prefix Sum and Fast & Slow Pointers | Solve range-sum, subarray and cycle problems |
| 23 | Greedy Algorithms and Dynamic Programming | Solve one basic problem for each technique |
| 24 | Bit Manipulation and Disjoint Set (Union-Find) | Practise bit operations and connected components |
| 25 | Segment Trees, Fenwick Trees, Monotonic Stack and Queue | Understand use cases and solve one basic monotonic-stack problem |

## Daily One-Hour Study Structure

| Activity | Duration |
|---|---:|
| Understand the concept | 10 minutes |
| Dry-run with examples | 15 minutes |
| Python implementation and coding problems | 25 minutes |
| Complexity analysis and revision | 10 minutes |
| **Total** | **60 minutes** |

## Daily Progress Checklist

At the end of each session, verify:

- [ ] I can explain the concept without looking at notes.
- [ ] I can write the basic Python implementation myself.
- [ ] I can solve at least one related coding problem.
- [ ] I understand the time and space complexity.

## Learning Guidelines

1. Spend more time coding than watching tutorials.
2. Understand the logic instead of memorising code.
3. Dry-run algorithms using small examples.
4. Analyse time and space complexity.
5. Record mistakes and important observations.
6. Revise difficult topics before moving forward.

## Expected Outcome

After 25 days (25 learning hours), the objective is to understand the fundamentals of DSA, implement important data structures and algorithms in Python, and solve beginner-level problems across the major DSA topics.

**Note:** This is Phase 1 – DSA Foundation. Additional problem-solving practice will be required to develop interview-level proficiency.
