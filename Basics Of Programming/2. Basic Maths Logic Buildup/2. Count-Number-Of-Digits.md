# Python Program to Count Number of Digits

> 📚 **Source:** [codeanddebug.in — Count Number of Digits](https://codeanddebug.in/blog/python-program-to-count-number-of-digits/)

Counting the number of digits in an integer is a classic beginner problem that strengthens your understanding of **loops** and **digit extraction**. We will look at **three** different approaches.

---

## Problem Statement

> Given an integer `n`, count how many digits it contains.

**Examples:**
```
Input:  12345   →  Output: 5
Input:  7       →  Output: 1
Input:  1000    →  Output: 4
```

---

## Approach 1: Using a Loop (Digit Extraction)

The idea is to keep removing the last digit using `// 10` and increase a counter until the number becomes `0`.

```python
def count_digits(n):
    n = abs(n)          # handle negatives
    count = 0

    if n == 0:
        return 1        # 0 itself has one digit

    while n > 0:
        count += 1
        n = n // 10     # remove last digit

    return count


print(count_digits(12345))   # 5
```

### Dry Run for `n = 12345`

| Step | `n`   | `count` |
|------|-------|---------|
| 1    | 12345 | 1       |
| 2    | 1234  | 2       |
| 3    | 123   | 3       |
| 4    | 12    | 4       |
| 5    | 1     | 5       |
| end  | 0     | 5       |

- **Time Complexity:** O(log₁₀ n)
- **Space Complexity:** O(1)

---

## Approach 2: Using `len()` and String Conversion

Convert the number to a string and measure its length. Simple and Pythonic.

```python
def count_digits(n):
    return len(str(abs(n)))


print(count_digits(12345))   # 5
```

> ⚠️ Remember to use `abs(n)` — otherwise the minus sign `-` would be counted as a character for negative numbers.

- **Time Complexity:** O(log₁₀ n) (conversion cost)
- **Space Complexity:** O(log₁₀ n) (string created)

---

## Approach 3: Using Logarithm (Math Formula)

The number of digits in a positive integer `n` is `floor(log₁₀(n)) + 1`.

```python
import math

def count_digits(n):
    n = abs(n)
    if n == 0:
        return 1
    return int(math.log10(n)) + 1


print(count_digits(12345))   # 5
```

- **Time Complexity:** O(1)
- **Space Complexity:** O(1)

> This is the **most efficient** approach, but be careful with the `n == 0` edge case since `log10(0)` is undefined.

---

## Comparison of Approaches

| Approach         | Time       | Space      | Notes                          |
|------------------|------------|------------|--------------------------------|
| Loop             | O(log n)   | O(1)       | Best for learning the logic    |
| String `len()`   | O(log n)   | O(log n)   | Shortest, most Pythonic        |
| Logarithm        | O(1)       | O(1)       | Fastest, watch the 0 edge case |

---

## Edge Cases

1. **Zero** → should return `1`.
2. **Negative numbers** → use `abs()` so the sign is not counted.
3. **Very large numbers** → the loop and string methods handle arbitrary precision well in Python.
