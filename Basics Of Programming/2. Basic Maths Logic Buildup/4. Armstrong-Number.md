# Python Program to Check Armstrong Number

> 📚 **Source:** [codeanddebug.in — Check Armstrong Number](https://codeanddebug.in/blog/python-program-to-check-armstrong-number/)

An **Armstrong number** (also called a *narcissistic number*) is a number that equals the **sum of its own digits, each raised to the power of the number of digits**.

---

## What is an Armstrong Number?

For a number with `d` digits, it is an Armstrong number if:

```
number = (digit₁)^d + (digit₂)^d + ... + (digitₙ)^d
```

### Examples

**153** (3 digits):
```
1³ + 5³ + 3³ = 1 + 125 + 27 = 153  ✅  Armstrong
```

**9474** (4 digits):
```
9⁴ + 4⁴ + 7⁴ + 4⁴ = 6561 + 256 + 2401 + 256 = 9474  ✅  Armstrong
```

**123** (3 digits):
```
1³ + 2³ + 3³ = 1 + 8 + 27 = 36 ≠ 123  ❌  Not Armstrong
```

---

## Step-by-Step Logic

1. **Count the number of digits** (`d`) in the number.
2. **Extract each digit** using `% 10` and `// 10`.
3. **Raise each digit** to the power `d` and **add** to a running sum.
4. **Compare** the sum with the original number.

---

## Program: Check Armstrong Number

```python
def is_armstrong(n):
    original = n

    # Step 1: count number of digits
    num_digits = len(str(n))

    # Step 2 & 3: sum of each digit raised to power
    total = 0
    temp = n
    while temp > 0:
        digit = temp % 10
        total += digit ** num_digits
        temp = temp // 10

    # Step 4: compare
    return total == original


print(is_armstrong(153))    # True
print(is_armstrong(9474))   # True
print(is_armstrong(123))    # False
```

---

## Dry Run for `n = 153`

Number of digits `d = 3`.

| Step | `temp` | `digit` | `digit³` | `total`            |
|------|--------|---------|----------|--------------------|
| 1    | 153    | 3       | 27       | 27                 |
| 2    | 15     | 5       | 125      | 152                |
| 3    | 1      | 1       | 1        | 153                |
| end  | 0      | —       | —        | 153                |

`total (153) == original (153)` → **Armstrong** ✅

## Pythonic One-Liner Version

```python
def is_armstrong(n):
    d = len(str(n))
    return n == sum(int(digit) ** d for digit in str(n))


print(is_armstrong(370))   # True (3³ + 7³ + 0³ = 370)
```

---

## Complexity Analysis

- **Time Complexity:** O(d) where `d` is the number of digits (i.e., O(log₁₀ n)).
- **Space Complexity:** O(1).

---

## Edge Cases

1. **Single-digit numbers** (`0`–`9`) are all Armstrong numbers, since `d = 1` and `digit¹ = digit`.
2. **Negative numbers** are generally **not** considered Armstrong numbers.

---

## Key Takeaway

> Armstrong = sum of each digit raised to the **count of digits**.
> It combines two core skills: **counting digits** + **extracting digits**.
