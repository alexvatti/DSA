# Palindrome Number Program in Python

> 📚 **Source:** [codeanddebug.in — Palindrome Number Program in Python](https://codeanddebug.in/blog/palindrome-number-program-in-python/)

A **palindrome number** is a number that reads the **same forwards and backwards**. This problem builds directly on the *digit extraction* technique.

---

## Problem Statement

> Given an integer, check whether it is a palindrome.

**Examples:**
```
121    →  Palindrome      (reverse is 121)
12321  →  Palindrome      (reverse is 12321)
123    →  Not Palindrome  (reverse is 321)
-121   →  Not Palindrome  (the '-' breaks symmetry)
```

---

## The Core Logic

The idea is to **reverse the number** and compare it with the original. If they are equal, it is a palindrome.

### How to Reverse a Number

```
reversed = reversed * 10 + (n % 10)
n = n // 10
```

We pull off the last digit and "push" it onto the reversed number.

---

## Dry Run for `n = 121`

| Step | `n`  | `last = n % 10` | `reversed = reversed*10 + last` |
|------|------|-----------------|---------------------------------|
| 1    | 121  | 1               | 0*10 + 1 = 1                    |
| 2    | 12   | 2               | 1*10 + 2 = 12                   |
| 3    | 1    | 1               | 12*10 + 1 = 121                 |
| end  | 0    | —               | 121                             |

`reversed (121) == original (121)` → **Palindrome** ✅

---

## Program 1: Reverse and Compare (Number Approach)

```python
def is_palindrome(n):
    # Negative numbers are not palindromes
    if n < 0:
        return False

    original = n
    reversed_num = 0

    while n > 0:
        last_digit = n % 10
        reversed_num = reversed_num * 10 + last_digit
        n = n // 10

    return original == reversed_num


print(is_palindrome(121))    # True
print(is_palindrome(123))    # False
```

- **Time Complexity:** O(log₁₀ n)
- **Space Complexity:** O(1)

---

## Program 2: Using String Reversal (Pythonic)

```python
def is_palindrome(n):
    if n < 0:
        return False
    s = str(n)
    return s == s[::-1]      # s[::-1] reverses the string


print(is_palindrome(12321))  # True
```

> `s[::-1]` is Python's slicing trick to reverse any sequence.

- **Time Complexity:** O(log₁₀ n)
- **Space Complexity:** O(log₁₀ n) (string copy)

---

## Important Edge Cases

1. **Negative numbers** (e.g., `-121`) are **not** palindromes because of the leading `-` sign.
2. **Single-digit numbers** (`0`–`9`) are always palindromes.
3. **Numbers ending in 0** (except 0 itself) can never be palindromes, because no number starts with 0 (e.g., `10` reversed is `01 = 1`).

---

## Key Takeaway

> The pattern `reversed = reversed * 10 + (n % 10)` is used to **reverse any integer**.
> Compare it with the original to decide if it's a palindrome.
