# Extraction of Digits in Python

> 📚 **Source:** [codeanddebug.in — Extraction of Digits in Python](https://codeanddebug.in/blog/extraction-of-digits-in-python/)

Extracting individual digits from a number is one of the **most fundamental building blocks** in programming. Many problems — like counting digits, reversing a number, checking palindromes, and Armstrong numbers — all rely on this single technique.

---

## The Core Idea

To extract digits from a number, we use two operators:

| Operator | Name            | Purpose                                      |
|----------|-----------------|----------------------------------------------|
| `%`      | Modulo          | Gives the **remainder** → extracts last digit |
| `//`     | Floor Division  | **Removes** the last digit                   |

### Key Formulas

```
last_digit = number % 10      # extract the last digit
number     = number // 10     # remove the last digit
```

### Why Does `% 10` Give the Last Digit?

When you divide any number by 10, the remainder is always the last digit.

```
2345 % 10 = 5   (last digit)
2345 // 10 = 234 (number without last digit)
```

---

## Step-by-Step Dry Run

Let's extract digits from `n = 2345`:

| Step | `n`  | `n % 10` (digit) | `n // 10` (new n) |
|------|------|------------------|-------------------|
| 1    | 2345 | **5**            | 234               |
| 2    | 234  | **4**            | 23                |
| 3    | 23   | **3**            | 2                 |
| 4    | 2    | **2**            | 0                 |

Loop stops when `n` becomes `0`. Digits extracted (in reverse): `5, 4, 3, 2`.

---

## Program 1: Extract and Print Each Digit

```python
def extract_digits(n):
    # Handle negative numbers
    n = abs(n)

    # Special case: if number is 0
    if n == 0:
        print(0)
        return

    while n > 0:
        last_digit = n % 10   # get last digit
        print(last_digit)
        n = n // 10           # remove last digit


extract_digits(2345)
```

**Output:**
```
5
4
3
2
```

> Note: Digits are printed from **last to first** because we keep peeling off the last digit.

---

## Program 2: Store Digits in a List

```python
def get_digits(n):
    n = abs(n)
    digits = []

    if n == 0:
        return [0]

    while n > 0:
        digits.append(n % 10)
        n = n // 10

    digits.reverse()   # to keep original order
    return digits


print(get_digits(2345))   # [2, 3, 4, 5]
```

---

## Edge Cases to Remember

1. **Zero (`0`)** — The `while n > 0` loop never runs, so handle it separately.
2. **Negative numbers** — Use `abs(n)` first, otherwise the loop may behave unexpectedly.
3. **Single-digit numbers** — Works fine, the loop runs just once.

---

## Complexity Analysis

- **Time Complexity:** **O(log₁₀ n)** — The number of digits in `n` is proportional to `log₁₀(n)`. We reduce `n` by a factor of 10 each iteration.
- **Space Complexity:** **O(1)** for printing, **O(log₁₀ n)** if we store digits in a list.

---

## Key Takeaway

> `n % 10` gives you the **last digit**, and `n // 10` **removes** it.
> Master this pattern — it is the base of dozens of number-based problems.
