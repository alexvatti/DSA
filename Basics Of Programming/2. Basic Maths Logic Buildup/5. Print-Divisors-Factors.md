# Python Program to Print Divisors (Factors) of an Integer

> 📚 **Source:** [codeanddebug.in — Print Divisors (Factors) of an Integer](https://codeanddebug.in/blog/python-program-print-divisors-factors-integer/)

A **divisor** (or **factor**) of a number `n` is any integer that divides `n` **completely**, leaving no remainder. This problem is a great introduction to **optimization** using mathematical properties.

---

## Problem Statement

> Given an integer `n`, print all of its divisors.

**Example:**
```
Input:  36
Output: 1 2 3 4 6 9 12 18 36
```

A number `i` is a divisor of `n` if `n % i == 0`.

---

## Approach 1: Brute Force — O(n)

Check every number from `1` to `n`.

```python
def print_divisors(n):
    for i in range(1, n + 1):
        if n % i == 0:
            print(i, end=" ")


print_divisors(36)
# 1 2 3 4 6 9 12 18 36
```

- **Time Complexity:** O(n) — we check all numbers up to `n`.
- **Space Complexity:** O(1).

This works but is **slow** for large numbers.

---

## Approach 2: Optimized — O(√n)

### The Key Insight

Divisors always come in **pairs**. If `i` divides `n`, then `n / i` also divides `n`.

```
For n = 36:
1 × 36
2 × 18
3 × 12
4 × 9
6 × 6
```

Notice every pair has one factor `≤ √36 = 6` and one factor `≥ 6`. So we only need to loop up to **√n** and grab both factors of each pair.

```python
import math

def print_divisors(n):
    divisors = []

    i = 1
    while i * i <= n:          # loop only up to √n
        if n % i == 0:
            divisors.append(i)       # smaller factor
            if i != n // i:          # avoid duplicate for perfect squares
                divisors.append(n // i)   # larger factor
        i += 1

    divisors.sort()            # sort to print in order
    print(*divisors)


print_divisors(36)
# 1 2 3 4 6 9 12 18 36
```

### Dry Run for `n = 36`

| `i` | `i*i` | `n % i == 0`? | Factors added |
|-----|-------|---------------|---------------|
| 1   | 1     | Yes           | 1, 36         |
| 2   | 4     | Yes           | 2, 18         |
| 3   | 9     | Yes           | 3, 12         |
| 4   | 16    | Yes           | 4, 9          |
| 5   | 25    | No            | —             |
| 6   | 36    | Yes           | 6 (only once) |

> When `i == n // i` (as in `6 × 6`), we add it **only once** to avoid duplicates.

- **Time Complexity:** O(√n) — massive improvement!
- **Space Complexity:** O(√n) to store divisors (O(1) if printed directly).

---

## Comparison

| Approach    | Time      | Best For                      |
|-------------|-----------|-------------------------------|
| Brute Force | O(n)      | Small numbers / learning      |
| Optimized   | O(√n)     | Large numbers / efficiency    |

For `n = 1,000,000`: brute force does **1 million** checks, while the optimized version does only **1,000** checks.

---

## Edge Cases

1. **`n = 1`** → only divisor is `1`.
2. **Perfect squares** (`36`, `49`) → the square root must be counted only once.
3. **Prime numbers** → have exactly two divisors: `1` and the number itself.

---

## Key Takeaway

> Divisors occur in **pairs** around **√n**.
> Looping only up to √n reduces time complexity from **O(n)** to **O(√n)**.
