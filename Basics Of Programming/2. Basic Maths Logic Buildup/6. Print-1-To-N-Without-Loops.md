# Python Program to Print 1 to N Without Loops

> 📚 **Source:** [codeanddebug.in — Print 1 to N Without Loops](https://codeanddebug.in/blog/python-program-print-1-to-n-without-loops/)

How do you print numbers from `1` to `N` **without using any loop** (`for` / `while`)? The answer is **recursion** — a function that calls itself. This problem is a perfect bridge into the world of recursion.

---

## Problem Statement

> Print numbers from `1` to `N` without using any loop.

**Example:**
```
Input:  N = 5
Output: 1 2 3 4 5
```

---

## What is Recursion?

**Recursion** is when a function calls **itself** to solve a smaller version of the same problem.

Every recursive function needs two things:
1. **Base Case** — the condition to **stop** the recursion.
2. **Recursive Case** — the function calling itself with a **smaller** input.

> Without a base case, recursion runs forever and crashes with a *RecursionError* (stack overflow).

---

## Approach 1: Print 1 to N (Increasing Order)

Here we print **first**, then recurse. We count **up** from 1 to N.

```python
def print_1_to_n(current, n):
    # Base case: stop when we pass n
    if current > n:
        return

    print(current, end=" ")          # print first
    print_1_to_n(current + 1, n)     # then recurse with next number


print_1_to_n(1, 5)
# 1 2 3 4 5
```

### How It Works (Call Stack)

```
print_1_to_n(1, 5)  → prints 1 → calls print_1_to_n(2, 5)
print_1_to_n(2, 5)  → prints 2 → calls print_1_to_n(3, 5)
print_1_to_n(3, 5)  → prints 3 → calls print_1_to_n(4, 5)
print_1_to_n(4, 5)  → prints 4 → calls print_1_to_n(5, 5)
print_1_to_n(5, 5)  → prints 5 → calls print_1_to_n(6, 5)
print_1_to_n(6, 5)  → 6 > 5, base case hit → return
```

---

## Approach 2: Print N to 1 (Decreasing Order)

```python
def print_n_to_1(n):
    # Base case
    if n == 0:
        return

    print(n, end=" ")       # print first
    print_n_to_1(n - 1)     # then recurse downward


print_n_to_1(5)
# 5 4 3 2 1
```

---

## Approach 3: The Clever Trick — Print 1 to N Using a Single Argument

By changing the **order** of `print` and the recursive call, we can print `1 to N` while counting **down**. This uses the magic of **backtracking** — statements after the recursive call run in reverse order.

```python
def print_1_to_n(n):
    if n == 0:
        return

    print_1_to_n(n - 1)    # recurse FIRST (go all the way down)
    print(n, end=" ")      # print AFTER returning (on the way back up)


print_1_to_n(5)
# 1 2 3 4 5
```

### Why Does This Print in Increasing Order?

Because the `print` statement runs **after** the recursive call returns. The calls "stack up" to `n = 1` first, and then print as the stack **unwinds**:

```
print_1_to_n(5) → calls print_1_to_n(4)
  print_1_to_n(4) → calls print_1_to_n(3)
    print_1_to_n(3) → calls print_1_to_n(2)
      print_1_to_n(2) → calls print_1_to_n(1)
        print_1_to_n(1) → calls print_1_to_n(0) → returns
        print 1
      print 2
    print 3
  print 4
print 5
```

---

## Complexity Analysis

- **Time Complexity:** O(n) — one call per number.
- **Space Complexity:** O(n) — the recursion **call stack** holds up to `n` frames.

> Unlike a loop (O(1) space), recursion uses O(n) extra space due to the call stack. This is an important trade-off to remember.

---

## Key Takeaways

- Recursion replaces loops by having a function **call itself**.
- Always define a **base case** to stop infinite recursion.
- The **position** of the `print` statement (before vs. after the recursive call) decides whether you print in **increasing** or **decreasing** order.
