# Find Factorial of a Number Using Recursion

> 📚 **Source:** [codeanddebug.in — Find Factorial of Number Using Recursion](https://codeanddebug.in/blog/find-factorial-of-number-using-recursion/)

The **factorial** of a number is a classic example to understand **recursion**. It demonstrates perfectly how a problem can be broken down into smaller, identical sub-problems.

---

## What is Factorial?

The factorial of a non-negative integer `n` (written as `n!`) is the product of all positive integers from `1` to `n`.

```
n! = n × (n-1) × (n-2) × ... × 2 × 1
```

**Examples:**
```
5! = 5 × 4 × 3 × 2 × 1 = 120
3! = 3 × 2 × 1 = 6
0! = 1   (by definition)
1! = 1
```

---

## The Recursive Insight

Notice that factorial can be defined **in terms of itself**:

```
5! = 5 × 4!
4! = 4 × 3!
3! = 3 × 2!
...
```

In general:

```
n! = n × (n-1)!
```

This is a **recursive relationship**. It gives us:
- **Recursive Case:** `factorial(n) = n * factorial(n - 1)`
- **Base Case:** `factorial(0) = 1` (stops the recursion)

---

## Program: Factorial Using Recursion

```python
def factorial(n):
    # Base case: 0! = 1 and 1! = 1
    if n == 0 or n == 1:
        return 1

    # Recursive case
    return n * factorial(n - 1)


print(factorial(5))   # 120
print(factorial(0))   # 1
```

---

## How It Works — The Call Stack

Let's trace `factorial(5)`:

### Going Down (building the stack)

```
factorial(5) = 5 * factorial(4)
factorial(4) = 4 * factorial(3)
factorial(3) = 3 * factorial(2)
factorial(2) = 2 * factorial(1)
factorial(1) = 1          ← base case reached!
```

### Coming Back Up (unwinding the stack)

```
factorial(1) = 1
factorial(2) = 2 * 1   = 2
factorial(3) = 3 * 2   = 6
factorial(4) = 4 * 6   = 24
factorial(5) = 5 * 24  = 120   ← final answer
```

> Each function call **waits** for the result of the smaller call before it can compute its own answer.

---

## Iterative Version (For Comparison)

The same can be done with a simple loop:

```python
def factorial(n):
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result


print(factorial(5))   # 120
```

---

## Recursion vs. Iteration

| Aspect            | Recursion            | Iteration (Loop)    |
|-------------------|----------------------|---------------------|
| **Code clarity**  | Elegant, concise     | More explicit       |
| **Time**          | O(n)                 | O(n)                |
| **Space**         | O(n) (call stack)    | O(1)                |
| **Risk**          | Stack overflow for large `n` | No such risk |

---

## Complexity Analysis

- **Time Complexity:** O(n) — there are `n` recursive calls.
- **Space Complexity:** O(n) — the call stack holds `n` frames at its deepest point.

---

## Edge Cases

1. **`factorial(0)`** → must return `1` (this is the base case).
2. **Negative numbers** → factorial is undefined; you may raise an error.
3. **Large `n`** → recursion may hit Python's recursion limit (~1000). Use iteration for very large values.

---

## Key Takeaway

> Recursion works by breaking a problem into a **smaller identical sub-problem** (`n × (n-1)!`) and a **base case** (`0! = 1`) that stops it.
