# Palindrome String — Recursive and Iterative Solution

> 📚 **Source:** [codeanddebug.in — Palindrome String Recursive & Iterative Solution](https://codeanddebug.in/blog/palindrome-string-recursive-iterative-solution/)

A **palindrome string** reads the **same forwards and backwards**. Examples: `"madam"`, `"racecar"`, `"level"`. We'll solve this using both **iterative (two-pointer)** and **recursive** techniques.

---

## Problem Statement

> Given a string, check if it is a palindrome.

**Examples:**
```
"madam"    →  True
"racecar"  →  True
"hello"    →  False
"a"        →  True  (single char)
```

---

## Approach 1: Two-Pointer (Iterative)

Compare characters from **both ends**, moving inward. If any pair doesn't match, it's not a palindrome.

```python
def is_palindrome(s):
    left = 0
    right = len(s) - 1

    while left < right:
        if s[left] != s[right]:
            return False       # mismatch found
        left += 1
        right -= 1

    return True                # all pairs matched


print(is_palindrome("madam"))   # True
print(is_palindrome("hello"))   # False
```

### Dry Run for `"madam"`

| `left` | `right` | `s[left]` | `s[right]` | Match? |
|--------|---------|-----------|------------|--------|
| 0      | 4       | m         | m          | ✅     |
| 1      | 3       | a         | a          | ✅     |
| 2      | 2       | —         | —          | stop   |

All matched → **Palindrome** ✅

- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

---

## Approach 2: Recursion

Check the **outer** characters, then recurse on the **inner** substring.

```python
def is_palindrome(s, left, right):
    # Base case: pointers met or crossed → palindrome
    if left >= right:
        return True

    # If outer characters don't match → not a palindrome
    if s[left] != s[right]:
        return False

    # Recurse inward
    return is_palindrome(s, left + 1, right - 1)


text = "racecar"
print(is_palindrome(text, 0, len(text) - 1))   # True
```

### How the Recursion Flows for `"racecar"`

```
is_palindrome("racecar", 0, 6)  → 'r' == 'r' → recurse
  is_palindrome("racecar", 1, 5)  → 'a' == 'a' → recurse
    is_palindrome("racecar", 2, 4)  → 'c' == 'c' → recurse
      is_palindrome("racecar", 3, 3)  → left >= right → return True
```

Each level returns `True` up the chain → final answer **True**.

- **Time Complexity:** O(n) — n/2 recursive calls.
- **Space Complexity:** O(n) — recursion call stack.

---

## Approach 3: Pythonic One-Liner

```python
def is_palindrome(s):
    return s == s[::-1]      # compare string with its reverse


print(is_palindrome("level"))   # True
```

- **Time Complexity:** O(n)
- **Space Complexity:** O(n) (reversed copy created)

---

## Handling Case & Spaces (Sentence Palindromes)

For phrases like `"A man a plan a canal Panama"`, clean the string first:

```python
def is_palindrome(s):
    # Keep only alphanumeric chars, convert to lowercase
    cleaned = ''.join(ch.lower() for ch in s if ch.isalnum())
    return cleaned == cleaned[::-1]


print(is_palindrome("A man a plan a canal Panama"))   # True
```

## Comparison

| Approach      | Time  | Space | Notes                       |
|---------------|-------|-------|-----------------------------|
| Two-Pointer   | O(n)  | O(1)  | Most efficient              |
| Recursion     | O(n)  | O(n)  | Elegant, uses call stack    |
| Slicing       | O(n)  | O(n)  | Shortest to write           |

---

## Edge Cases

1. **Empty string `""`** → considered a palindrome (`True`).
2. **Single character** → always a palindrome.
3. **Mixed case / spaces** → normalize the string first (see above).

---

## Key Takeaway

> Both palindrome checking and array reversal use the same **two-pointer** pattern — compare/swap from both ends and move inward.
> The two-pointer iterative method gives the best **O(n) time, O(1) space**.
