# Reverse an Array Using Recursion and While Loop

> 📚 **Source:** [codeanddebug.in — Reverse Array Using Recursion and While Loop](https://codeanddebug.in/blog/reverse-array-using-recursion-and-while-loop/)

Reversing an array is a fundamental operation. We'll explore it using the **Two-Pointer technique** (both iterative and recursive), which is far more efficient than creating a new array.

---

## Problem Statement

> Given an array, reverse its elements **in place**.

**Example:**
```
Input:  [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]
```

---

## The Two-Pointer Idea

Place one pointer at the **start** (`left`) and one at the **end** (`right`). Swap the two elements, then move the pointers **toward each other**. Stop when they meet in the middle.

```
[1, 2, 3, 4, 5]
 L           R     → swap(1,5) → [5, 2, 3, 4, 1]
    L     R        → swap(2,4) → [5, 4, 3, 2, 1]
       L R         → left >= right, stop
```

Only `n/2` swaps are needed!

---

## Approach 1: Using a While Loop (Iterative)

```python
def reverse_array(arr):
    left = 0
    right = len(arr) - 1

    while left < right:
        # Swap elements at left and right
        arr[left], arr[right] = arr[right], arr[left]

        # Move pointers toward the center
        left += 1
        right -= 1

    return arr


print(reverse_array([1, 2, 3, 4, 5]))   # [5, 4, 3, 2, 1]
```

- **Time Complexity:** O(n) — we visit each element once (n/2 swaps).
- **Space Complexity:** O(1) — reversed in place, no extra array.

---

## Approach 2: Using Recursion

The same two-pointer logic can be expressed recursively. We swap the outer pair, then recurse inward.

```python
def reverse_array(arr, left, right):
    # Base case: pointers meet or cross
    if left >= right:
        return

    # Swap the outer elements
    arr[left], arr[right] = arr[right], arr[left]

    # Recurse on the inner part
    reverse_array(arr, left + 1, right - 1)


nums = [1, 2, 3, 4, 5]
reverse_array(nums, 0, len(nums) - 1)
print(nums)   # [5, 4, 3, 2, 1]
```

### Dry Run for `[1, 2, 3, 4, 5]`

| Call                    | `left` | `right` | Action           | Array             |
|-------------------------|--------|---------|------------------|-------------------|
| reverse(arr, 0, 4)      | 0      | 4       | swap 1 & 5       | [5, 2, 3, 4, 1]   |
| reverse(arr, 1, 3)      | 1      | 3       | swap 2 & 4       | [5, 4, 3, 2, 1]   |
| reverse(arr, 2, 2)      | 2      | 2       | base case, stop  | [5, 4, 3, 2, 1]   |

- **Time Complexity:** O(n) — n/2 recursive calls.
- **Space Complexity:** O(n) — recursion call stack (O(n/2) depth).

---

## Approach 3: Pythonic One-Liners

Python offers super-short built-in ways to reverse:

```python
arr = [1, 2, 3, 4, 5]

# Method A: slicing (creates a new list)
reversed_arr = arr[::-1]

# Method B: built-in reverse() (in place)
arr.reverse()

# Method C: reversed() function
reversed_arr = list(reversed(arr))
```

> While elegant, you should still know the **two-pointer** method — it is what interviewers want to see.

---

## Comparison

| Approach        | Time  | Space | In-Place? |
|-----------------|-------|-------|-----------|
| While loop      | O(n)  | O(1)  | Yes       |
| Recursion       | O(n)  | O(n)  | Yes       |
| Slicing `[::-1]`| O(n)  | O(n)  | No        |

---

## Key Takeaway

> The **two-pointer swap** is the optimal way to reverse an array: **O(n) time, O(1) space**.
> The recursive version shows the same logic but costs **O(n)** stack space.
