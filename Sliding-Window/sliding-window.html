🤔 What is the Sliding Window technique?

Sliding window is one of the most frequently asked interview patterns. It works on problems where you need to find something (maximum, minimum, count) within a contiguous subarray or substring. Instead of re-checking every subarray from scratch (O(n²)), you keep a window between two pointers (left and right) and slide it forward: add the new element entering on the right, remove the old one leaving on the left. Nothing is recomputed, so the time drops to O(n).

✅ When to use it

  • The problem involves a subarray or substring
  • You need to optimize a brute-force approach
  • You want the longest, shortest, max, min or count of a contiguous range
  • Keywords: at most K, permutation, every window

💡 Key idea

Maintain a window (two pointers) and expand or shrink it based on a condition. As the window slides forward you add new elements and remove old ones, avoiding recomputation.

🔍 How to spot it

A contiguous subarray/substring plus a "longest / shortest / max / count" goal? Think sliding window first. Is the size K given? Fixed window. Otherwise it is a variable window.

📏 Fixed Window

0 · Contains Duplicate 🔎 Hash Set

🔗 LeetCode 217 Easy

The gateway skill for sliding windows: ask "have I seen this value before?" in O(1) using a set. One pass is all it takes.

  1. Walk through each number once.
  2. If the number is already in the set → duplicate → return True.
  3. Otherwise add it to the set.
  4. Finished with no clash → return False.
Python solution 
def contains_duplicate(nums: list[int]) -> bool:
    seen = set()

    for num in nums:
        # Already inside the set -> we found a repeat
        if num in seen:
            return True
        seen.add(num)

    return False

1 · Contains Duplicate II 📏 Fixed Window

🔗 LeetCode 219 Easy

Keep a set of the last k values. If the new value is already inside that window, a duplicate exists within distance k.

  1. Move right forward through the array.
  2. If nums[right] is already in the window → duplicate within k → True.
  3. Add nums[right] to the window.
  4. If the window holds more than k values, drop nums[right − k].
Python solution 
def contains_nearby_duplicate(nums: list[int], k: int) -> bool:
    window = set()

    for right in range(len(nums)):
        # A match inside the window means distance <= k
        if nums[right] in window:
            return True

        window.add(nums[right])

        # Keep the window to at most k elements
        if len(window) > k:
            window.remove(nums[right - k])

    return False

2 · Best Time to Buy and Sell Stock ↔️ Variable Window

🔗 LeetCode 121 Easy

Treat left as the buy day (cheapest price so far) and right as the sell day. Slide right forward and track the best profit.

  1. Start left = 0 (buy on day 0), best = 0.
  2. Move right forward.
  3. If prices[right] < prices[left] → found a cheaper buy day, slide left here.
  4. Otherwise profit = prices[right] − prices[left] → update best.
Python solution 
def max_profit(prices: list[int]) -> int:
    left = 0            # buy day (cheapest so far)
    best = 0

    for right in range(1, len(prices)):
        if prices[right] < prices[left]:
            # Found a cheaper day to buy -> slide the window start
            left = right
        else:
            # Sell today against the cheapest buy day
            best = max(best, prices[right] - prices[left])

    return best

3 · Majority Element 🗳️ Boyer–Moore Voting

🔗 LeetCode 169 Easy

Keep a candidate and a count. Matching votes raise the count, different votes cancel it out. The majority element always survives.

  1. When count == 0 → adopt the current number as the candidate.
  2. Same as candidate → count += 1.
  3. Different → count −= 1.
  4. The final candidate is the majority element.
Python solution 
def majority_element(nums: list[int]) -> int:
    candidate = None
    count = 0

    for num in nums:
        if count == 0:
            candidate = num          # adopt a fresh candidate
        count += 1 if num == candidate else -1

    return candidate

4 · Most Frequent Even Element 📊 Frequency Map

🔗 LeetCode 2404 Easy

Count only the even numbers in a dict, then pick the winner by highest count — and on a tie, the smallest value.

  1. Walk through nums; if a number is even, increment its count.
  2. Track the best element: higher count wins.
  3. On a tie, the smaller value wins.
  4. No even numbers → return -1.
Python solution 
def most_frequent_even(nums: list[int]) -> int:
    count = {}
    for num in nums:
        if num % 2 == 0:                       # only even numbers
            count[num] = count.get(num, 0) + 1

    if not count:                             # no even element
        return -1

    best_val = -1
    best_count = 0
    for val, cnt in count.items():
        # higher count wins; on a tie pick the smaller value
        if cnt > best_count or (cnt == best_count and val < best_val):
            best_val = val
            best_count = cnt

    return best_val

5 · Longest Substring Without Repeating Characters ↔️ Variable Window

🔗 LeetCode 3 Medium

Keep a window of unique characters. When the new character is already inside, shrink from the left just enough to remove the duplicate.

  1. Move right forward one character at a time.
  2. While s[right] is already in the set → remove s[left], move left up.
  3. Add s[right] to the set. The window is valid again.
  4. Update the best length with right − left + 1.
Python solution 
def length_of_longest_substring(s: str) -> int:
    seen = set()
    left = 0
    best = 0

    for right in range(len(s)):
        # Shrink the window until the duplicate is gone
        while s[right] in seen:
            seen.remove(s[left])
            left += 1

        # Expand: add the new character
        seen.add(s[right])

        # Window is valid -> update the answer
        best = max(best, right - left + 1)

    return best

6 · Fruits Into Baskets ↔️ Variable Window

🔗 LeetCode 904 Medium

Two baskets means at most 2 distinct fruit types. Find the longest subarray that stays within that limit, using a dict of counts.

  1. Add fruits[right] to the count dict.
  2. While len(count) > 2 → decrease count[fruits[left]], delete the key at 0, move left up.
  3. The window is valid again: update the best length.
  4. Remember: delete a key when its count hits 0, or len() lies.
Python solution 
def total_fruit(fruits: list[int]) -> int:
    count = {}
    left = 0
    best = 0

    for right in range(len(fruits)):
        # Expand: take the fruit at `right`
        count[fruits[right]] = count.get(fruits[right], 0) + 1

        # Shrink while we hold more than 2 types
        while len(count) > 2:
            count[fruits[left]] -= 1
            if count[fruits[left]] == 0:
                del count[fruits[left]]
            left += 1

        best = max(best, right - left + 1)

    return best

7 · Longest Repeating Character Replacement ↔️ Variable Window

🔗 LeetCode 424 Medium

Replacements needed = window length − count of the most frequent letter. The window is valid while that number is ≤ k.

  1. Add s[right] to the letter counts.
  2. Compute (window length) − max(count.values()).
  3. While it is greater than k → remove s[left], move left up.
  4. Window valid: update the best length.
Python solution 
def character_replacement(s: str, k: int) -> int:
    count = {}
    left = 0
    best = 0

    for right in range(len(s)):
        # Expand
        count[s[right]] = count.get(s[right], 0) + 1

        # Shrink while we need more than k replacements
        while (right - left + 1) - max(count.values()) > k:
            count[s[left]] -= 1
            left += 1

        best = max(best, right - left + 1)

    return best

8 · Permutation in String 📏 Fixed Window

🔗 LeetCode 567 Medium

A permutation of s1 has the same length and the same letter counts, so slide a window of fixed size len(s1) across s2 and compare counts.

  1. Count the letters of s1 into need.
  2. For each i in s2: add s2[i] to the window counts.
  3. If i ≥ k, remove s2[i − k] (it just left the window).
  4. When the window is full, window == need → permutation found.
Python solution 
def check_inclusion(s1: str, s2: str) -> bool:
    k = len(s1)
    if k > len(s2):
        return False

    need = [0] * 26
    window = [0] * 26

    for ch in s1:
        need[ord(ch) - ord("a")] += 1

    for i in range(len(s2)):
        # Add the new character on the right
        window[ord(s2[i]) - ord("a")] += 1

        # Remove the character that fell out on the left
        if i >= k:
            window[ord(s2[i - k]) - ord("a")] -= 1

        # Window is full-size -> compare counts
        if i >= k - 1 and window == need:
            return True

    return False

9 · Minimum Window Substring ↔️ Variable Window (smallest)

🔗 LeetCode 76 Hard

Expand until the window contains everything in t, then shrink as far as possible while it stays valid. Track have vs required to check validity in O(1).

  1. Count the characters of t into need; required = len(need).
  2. Expand right. When a character's count reaches its need, have += 1.
  3. While have == required → record the window if it is smaller, then remove s[left].
  4. If removing breaks a requirement, have −= 1. Move left up.
Python solution 
def min_window(s: str, t: str) -> str:
    if not t or len(t) > len(s):
        return ""

    need = {}
    for ch in t:
        need[ch] = need.get(ch, 0) + 1

    window = {}
    have = 0
    required = len(need)

    best_len = float("inf")
    best_start = 0
    left = 0

    for right in range(len(s)):
        # Expand: add the new character
        ch = s[right]
        window[ch] = window.get(ch, 0) + 1
        if ch in need and window[ch] == need[ch]:
            have += 1

        # Shrink while the window is valid
        while have == required:
            if right - left + 1 < best_len:
                best_len = right - left + 1
                best_start = left

            out = s[left]
            window[out] -= 1
            if out in need and window[out] < need[out]:
                have -= 1
            left += 1

    return "" if best_len == float("inf") else s[best_start:best_start + best_len]

10 · Sliding Window Maximum 📏 Fixed Window + Deque

🔗 LeetCode 239 Hard

Keep a deque of indices whose values are in decreasing order. The front is always the maximum of the current window; smaller values behind a bigger one are useless, so they get popped.

  1. If the front index is outside the window (≤ i − k) → pop it from the front.
  2. While the back value is smaller than nums[i] → pop it from the back.
  3. Push index i.
  4. Once the first window is full (i ≥ k − 1), the answer is nums[deque[0]].
Python solution 
from collections import deque


def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq = deque()   # indices, values decreasing
    result = []

    for i in range(len(nums)):
        # 1. Drop the front if it slid out of the window
        if dq and dq[0] <= i - k:
            dq.popleft()

        # 2. Drop smaller values from the back
        while dq and nums[dq[-1]] < nums[i]:
            dq.pop()

        # 3. Add the current index
        dq.append(i)

        # 4. Window is full -> front is the maximum
        if i >= k - 1:
            result.append(nums[dq[0]])

    return result
