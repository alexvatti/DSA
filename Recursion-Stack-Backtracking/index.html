📦 Step 0 — Our own Stack (base code, written ONCE)

You already know stacks. This is the only stack we use in methods 3 and 4. Whenever a problem says “our own stack”, refer back to this code (file: code/stack_base.py).

class Stack:
    def __init__(self):
        self.items = []                 # the end of the list is the TOP

    def push(self, x):                  # put x on the TOP
        self.items.append(x)

    def pop(self):                      # remove and return the TOP
        return self.items.pop()

    def peek(self):                     # look at the TOP, do not remove
        return self.items[-1]

    def is_empty(self):                 # True when nothing is inside
        return len(self.items) == 0

    def size(self):
        return len(self.items)

push(x) puts x on top • pop() removes and returns the top • is_empty() tells if nothing is inside. In the code files: from stack_base import Stack
