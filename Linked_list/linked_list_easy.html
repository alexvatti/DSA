🤔 What is the Linked List technique?

A linked list is a chain of nodes. Each node holds a val and a next pointer; the last next is None. You cannot jump to index i — you must walk from the head. So nearly every problem is solved by moving one or two pointers along the chain and re-linking next arrows, in a single O(n) pass with O(1) extra space.

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

✅ When to use it

  • You need the middle, a cycle, or a node from the end
  • You must reverse or re-link nodes in place
  • You merge or compare two chains
  • Extra memory (array / set) is not allowed

💡 Key idea

Never lose the rest of the list: save next before you change it. Use prev / curr to flip arrows, slow / fast to find the middle or a loop, and a dummy head so the result never needs a special case.

🔍 How to spot it

The input is a ListNode and the words are reverse, middle, cycle, merge, palindrome, intersection. Need the middle or a loop? Slow & fast. Need to re-link? Prev / curr.
