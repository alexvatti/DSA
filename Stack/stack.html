🤔 What is the Stack technique?

A stack is Last-In-First-Out (LIFO): you only ever touch the top. That makes it perfect whenever the most recent unfinished thing must be handled first — matching brackets, undoing work, or finding the next greater / smaller element. Instead of re-scanning the array for every element (O(n²)), each element is pushed once and popped once, so the time drops to O(n).

✅ When to use it

  • Things must be matched or closed in reverse order
  • You need the next greater / smaller element for each position
  • You must track an aggregate after every undo (min, max)
  • Keywords: valid, nested, next warmer, largest rectangle, undo

💡 Key idea

Push items that are still waiting for something. When the thing they wait for arrives, pop and resolve them. For monotonic stacks, keep the stack sorted so only the top ever needs checking.

🔍 How to spot it

"Next greater / smaller / warmer"? Monotonic stack. Brackets or nesting? Plain stack. Need O(1) min/max after pops? Store the extra value next to each element.

1 · Valid Parentheses 🥞 Plain Stack

🔗 LeetCode 20 Easy

The last opener we saw must be the first one closed — that is exactly Last-In-First-Out.

  1. Walk through each character.
  2. Opener ( [ { → push it.
  3. Closer → the stack must be non-empty and its top must be the matching opener, then pop it. Otherwise → False.
  4. At the end the stack must be empty (no unmatched opener left).
Python solution 
def is_valid(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []

    for ch in s:
        if ch in pairs:
            # Closer -> top must be its matching opener
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
        else:
            # Opener -> wait for its closer
            stack.append(ch)

    # Every opener must have been matched
    return not stack

2 · Min Stack 🥞 Stack + Extra State

🔗 LeetCode 155 Medium

Every time we push, we also remember the minimum of everything at or below this element. The min never needs recomputing — it sits right next to the element.

  1. push(x): new min = x if the stack is empty, else min(x, current min). Push (x, new_min).
  2. pop(): remove the top pair — the min of what remains is already stored below it.
  3. top(): return the value of the top pair.
  4. getMin(): return the min of the top pair.
Python solution 
class MinStack:
    def __init__(self):
        self.stack = []  # each entry: (value, min so far)

    def push(self, val: int) -> None:
        # min of everything below, or the value itself if the stack is empty
        current_min = min(val, self.stack[-1][1]) if self.stack else val
        self.stack.append((val, current_min))

    def pop(self) -> None:
        self.stack.pop()

    def top(self) -> int:
        return self.stack[-1][0]

    def get_min(self) -> int:
        return self.stack[-1][1]

3 · Daily Temperatures 📉 Monotonic Stack

🔗 LeetCode 739 Medium

Keep a stack of indices of days still waiting for a warmer day. Their temperatures are always in decreasing order (that is why it is called monotonic). When today is warmer than the top, that day's wait is over.

  1. For each day i with temperature t.
  2. While the stack is non-empty and t is warmer than the day on top: pop j and set answer[j] = i - j.
  3. Push i (it now waits for its own warmer day).
  4. Days left on the stack never found one → they stay 0.
Python solution 
def daily_temperatures(temperatures: list[int]) -> list[int]:
    answer = [0] * len(temperatures)
    stack = []  # indices of days waiting for a warmer day

    for i, temp in enumerate(temperatures):
        # Today is warmer than the waiting days on top -> resolve them
        while stack and temp > temperatures[stack[-1]]:
            j = stack.pop()
            answer[j] = i - j
        stack.append(i)

    return answer

4 · Car Fleet 📉 Sort + Stack

🔗 LeetCode 853 Medium

Process cars from closest to the target to farthest. A car's solo arrival time is (target - position) / speed. If it would arrive no later than the fleet right ahead, it catches up and merges; if it arrives later, it forms a new fleet.

  1. Sort cars by position, largest first.
  2. For each car compute time = (target - pos) / speed.
  3. If the stack is empty or time is greater than the top → push (a new fleet).
  4. Otherwise (time ≤ top) it merges into the fleet ahead → do nothing.
  5. Answer = len(stack).
Python solution 
def car_fleet(target: int, position: list[int], speed: list[int]) -> int:
    # Closest to the target first
    cars = sorted(zip(position, speed), reverse=True)
    stack = []  # arrival time of each fleet

    for pos, spd in cars:
        time = (target - pos) / spd
        # Arrives later than the fleet ahead -> cannot catch it -> new fleet
        if not stack or time > stack[-1]:
            stack.append(time)
        # else: catches up and merges, nothing to push

    return len(stack)

5 · Largest Rectangle in Histogram 📈 Monotonic Stack

🔗 LeetCode 84 Hard

Keep bars in increasing height order. A bar can keep extending right until a shorter bar appears — then its rectangle is finished. The shorter bar inherits the start of everything it popped, because it can stretch back that far.

  1. For each bar i with height h, set start = i.
  2. While the top is taller than h: pop (idx, height), area = height * (i - idx), update the best, and set start = idx.
  3. Push (start, h).
  4. After the loop, every bar left can extend to the end: area = height * (n - idx).
Python solution 
def largest_rectangle_area(heights: list[int]) -> int:
    stack = []  # (start index, height), heights increasing
    best = 0

    for i, h in enumerate(heights):
        start = i
        # A shorter bar ends every taller bar on top of the stack
        while stack and stack[-1][1] > h:
            idx, height = stack.pop()
            best = max(best, height * (i - idx))
            start = idx          # the new bar can stretch back to here
        stack.append((start, h))

    # Bars left on the stack extend all the way to the end
    while stack:
        idx, height = stack.pop()
        best = max(best, height * (len(heights) - idx))

    return best
