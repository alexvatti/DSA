🤔 What is the Two Pointers technique?

The two-pointer pattern uses two variables (usually called left and right) that move through an array or string from different positions. Instead of checking every possible pair with two nested loops (O(n²)), the pointers move toward each other based on a condition — cutting the time complexity down to O(n) with O(1) space.

✅ When to use it

  • The input is sorted
  • You need to find a pair or triplet that meets a condition
  • You're comparing elements from both ends of an array
  • You must modify an array in place / remove items

💡 Key idea

Instead of brute-forcing every pair (O(n²)), two pointers move toward each other based on a rule. If the current state is too small, move one pointer up; too big, move the other down. This steers you to the answer in a single pass.

🔍 How to spot it

If the problem mentions a "sorted array" and asks you to find a pair or group of elements — think two pointers first. Comparing front vs back? Also two pointers.

1 · Valid Palindrome ↔️ Opposite Ends

🔗 LeetCode 125 Easy

Compare front vs back. Skip non-alphanumeric characters, lowercase everything, and check that left always matches right while moving inward.

  1. Put left at the start, right at the end.
  2. Skip any character that is not a letter/number.
  3. Compare left vs right (lowercased). Mismatch → not a palindrome.
  4. Move both pointers inward and repeat until they meet.
Python solution 
def is_palindrome(s):
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
        if s[left].lower() != s[right].lower():
            return False
        left += 1
        right -= 1
    return True

2 · Two Sum II (sorted) ↔️ Opposite Ends

🔗 LeetCode 167 Medium

Array is sorted, so move left up if the sum is too small, or right down if the sum is too big — steering toward the target.

  1. Set left=0 (smallest), right=end (largest).
  2. Compute sum = nums[left] + nums[right].
  3. Sum too small? Move left up. Too big? Move right down.
  4. Sum equals target → return the pair. 🎯
Python solution 
def two_sum_sorted(numbers, target):
    left, right = 0, len(numbers) - 1
    while left < right:
        s = numbers[left] + numbers[right]
        if s == target:
            return [left + 1, right + 1]
        elif s < target:
            left += 1   # need a bigger sum
        else:
            right -= 1  # need a smaller sum
    return []

3 · 3Sum 📌 Fix One + ↔️ Opposite Ends

🔗 LeetCode 15 Medium

Sort first, then fix nums[i] and run Two-Sum on the rest to find triplets that sum to 0. Duplicates are skipped automatically.

  1. Sort the array (unlocks pointers + easy dedup).
  2. Fix nums[i], then find two numbers summing to -nums[i].
  3. Use left=i+1, right=end. Sum<0 → left up; Sum>0 → right down.
  4. Sum=0 → record triplet, move both inward, and skip duplicates.
Python solution 
def three_sum(nums):
    nums.sort()
    result = []
    n = len(nums)
    for i in range(n):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        if nums[i] > 0:
            break
        left, right = i + 1, n - 1
        while left < right:
            s = nums[i] + nums[left] + nums[right]
            if s == 0:
                result.append([nums[i], nums[left], nums[right]])
                left += 1; right -= 1
                while left < right and nums[left] == nums[left - 1]:
                    left += 1
                while left < right and nums[right] == nums[right + 1]:
                    right -= 1
            elif s < 0:
                left += 1
            else:
                right -= 1
    return result

4 · Container With Most Water ↔️ Opposite Ends

🔗 LeetCode 11 Medium

Area = width × min(leftHeight, rightHeight). Always move the pointer on the shorter line — it's the only move that could find a bigger area.

  1. Start as wide as possible: left=0, right=end.
  2. Area = (right−left) × min(height[left], height[right]).
  3. Track the maximum area seen so far.
  4. Move the pointer at the shorter line inward, and repeat.
Python solution 
def max_area(height):
    left, right = 0, len(height) - 1
    best = 0
    while left < right:
        width = right - left
        current = width * min(height[left], height[right])
        best = max(best, current)
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1
    return best

5 · Trapping Rain Water ↔️ Opposite Ends

🔗 LeetCode 42 Hard

Water over a bar = min(leftMax, rightMax) − height. Always process the shorter side, keeping two running maxes.

  1. Start with left=0, right=end, and leftMax=rightMax=0.
  2. Look at the shorter side — its wall limits the water level.
  3. If the current bar is a new max, update the max (no water trapped here).
  4. Otherwise add max − height to the total, then step that pointer inward.
Python solution 
def trap(height):
    if not height:
        return 0
    left, right = 0, len(height) - 1
    left_max = right_max = water = 0
    while left < right:
        if height[left] < height[right]:
            if height[left] >= left_max:
                left_max = height[left]
            else:
                water += left_max - height[left]
            left += 1
        else:
            if height[right] >= right_max:
                right_max = height[right]
            else:
                water += right_max - height[right]
            right -= 1
    return water

6 · Remove Duplicates (sorted) ➡️ Slow & Fast

🔗 LeetCode 26 Easy

slow = write position, fast = scanner. When fast finds a value different from slow, advance slow and copy it there.

  1. slow=0 (first element is always unique).
  2. fast scans from index 1 to the end.
  3. If nums[fast] ≠ nums[slow] → new value: slow++, copy it over.
  4. If equal → duplicate, just let fast move on. Answer length = slow+1.
Python solution 
def remove_duplicates(nums):
    if not nums:
        return 0
    slow = 0
    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]
    return slow + 1
